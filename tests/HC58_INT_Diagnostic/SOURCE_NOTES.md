# Source Notes

The test is based on:

- the authoritative Big Dirty Save 14 HC58 transport pinout and SPI settings
- the post–Save 14 repository state only as a source reference; the production firmware is not modified by this diagnostic package
- Fixed Until Broken Rev C module wiring
- Motorola MC68HC58 interrupt, configuration-byte, status-byte, completion-code, and SPI servicing definitions

Important datasheet-derived rules implemented in the sketch:

- INT is active-low and generated by default when a frame completion code enters RxFIFO.
- IMSK=1 masks all interrupts; IMSK=0 enables them.
- IMOD remains 0 for this test.
- CS assertion and status read acknowledge/negate INT.
- RFS bits 7:5 identify whether the returned byte is data or a completion code.
- In serial mode, received data remains in RxFIFO until a flush-byte command is sent; the read and flush are combined with command `0x02`.
- Completion-code-at-head RFS values are 101, 110, and 111.
- The ISR never performs SPI, serial output, delays, decoding, or FIFO manipulation.
